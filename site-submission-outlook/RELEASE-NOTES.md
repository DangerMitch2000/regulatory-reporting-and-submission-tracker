Site Submission Outlook 1.0.0 shows current and following month planned submissions for ABO, ADJ, ADK, AJG, ARDG and SCR. Each planned-month column splits distinct submissions into In process and Submitted, based on the recorded actual submission date. The months advance automatically.

Click columns for searchable submission details. The visual includes totals, an overdue count within the displayed plan, site selection, an optional business-unit filter, light/dark themes and screenshot mode. Date conflicts, future actual dates and incomplete data delivery are shown explicitly.

Import `site-submission-outlook-1.0.0.0.pbiviz` and map Submission ID, Site, Initial planned submission date and Actual submission date. Business unit is optional. See `SITE-SUBMISSION-OUTLOOK-INSTALL.md` for the complete mapping and counting rules.

The package has a separate visual identity. The calculation, browser and packaged-runtime checks include 10,000 distinct submissions and 30,000 repeated source rows. Power BI Desktop/Service integration with the user's actual report data still requires validation. The demonstration records and preview image are fictional.
