# Dependencies and reused modules

The runtime reuses this repository's tracker date-format, assessment-response, event and dispatch-required modules, bundled locally. No external map, font or data service is used.

Build tooling uses Microsoft Power BI Visuals API 5.11.0, Power BI Visuals Tools 7.2.1, TypeScript 5.9.3, Playwright 1.55.1 and esbuild 0.25.10. Dependency packages retain their respective license files in an installed build environment. Power BI Visuals API/Tools and esbuild are MIT-licensed; TypeScript and Playwright use Apache-2.0. These are development/host-interface tools, not a claim of Microsoft certification.
