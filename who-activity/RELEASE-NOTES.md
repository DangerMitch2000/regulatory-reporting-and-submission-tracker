# WHO Submissions & Approvals 1.0.0

New Power BI visual for two-calendar-year actual activity, defaulting to WHO commercial region and ID business unit.

- Count distinct Submission IDs for actual submissions and distinct RO IDs for actual approvals.
- Adapt charts to the active sites, retaining the six standard sites in the filter and blank sites as Unassigned site.
- Flag blank commercial regions for review without assuming they identify WHO records.
- Filter by commercial region, site, business unit, product and submission type; group by site or region.
- Inspect the IDs and actual dates behind every card or bar, with search, copying and supplied platform links.
- Report unusable dates, conflicting links and partial delivery explicitly.
- Use compact responsive charts, Dark/Light themes, Wallace Sans typography and a clean screenshot layout.

Map Commercial region, Site, Submission ID, Actual submission date, RO ID and Actual RO approval date. Optional fields are described in the installation guide. The demo uses fictional data. This is an uncertified preview; screenshot mode does not enable native Power BI PowerPoint/PDF export.
